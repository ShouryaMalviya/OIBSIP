# AuthVault — Secure Authentication System
## Oasis Infobyte Web Development Internship — Level 2 Task 2

AuthVault is a responsive, modern client-side authentication demonstration system built exclusively with vanilla web technologies (HTML5, CSS3, ES6+ JavaScript, `localStorage`, `sessionStorage`, and the native Web Crypto API).

The complete project source code is organized within the [`AuthVault/`](file:///c:/Users/SHOURYA/OIBSIP/WebDev-L2-LoginSystem/AuthVault/) directory:

- [Registration Engine (`register.html`)](file:///c:/Users/SHOURYA/OIBSIP/WebDev-L2-LoginSystem/AuthVault/register.html)
- [Protected Dashboard (`dashboard.html`)](file:///c:/Users/SHOURYA/OIBSIP/WebDev-L2-LoginSystem/AuthVault/dashboard.html)
- [Design System Stylesheet (`css/style.css`)](file:///c:/Users/SHOURYA/OIBSIP/WebDev-L2-LoginSystem/AuthVault/css/style.css)

### Quick Start with Visual Studio Code

1. Open this repository folder in **VS Code**.
2. Right-click [`AuthVault/index.html`](file:///c:/Users/SHOURYA/OIBSIP/WebDev-L2-LoginSystem/AuthVault/index.html) and select **"Open with Live Server"**.
3. Or launch a static HTTP server:
   ```bash
   python -m http.server 8080
   ```
   and navigate to `http://localhost:8080/AuthVault/index.html`.
