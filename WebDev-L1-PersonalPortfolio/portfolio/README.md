# Shourya Malviya - Personal Portfolio

A professional, geometric, and modern personal portfolio website built for Level 1, Task 2 of the Web Development Internship.

## 🎯 Purpose
This portfolio serves as a digital identity for Shourya Malviya, a B.Tech Artificial Intelligence & Machine Learning student. It demonstrates proficiency in core frontend web technologies while showcasing technical skills, projects, and academic background in a clean, editorial layout.

## ✨ Features
- **Modern Geometric Design**: Custom layout utilizing asymmetric grids, fine borders, and a carefully selected color palette.
- **Fully Responsive**: Adapts seamlessly from large desktop monitors down to mobile screens.
- **Vanilla JavaScript Interactivity**: Includes smooth scrolling, dynamic navigation active states, mobile hamburger menu, form validation, and scroll-reveal animations.
- **Performance Optimized**: Built without heavy frameworks or libraries.
- **Accessibility Considered**: Semantic HTML5 structure, ARIA labels, keyboard navigability, and `prefers-reduced-motion` support.

## 🛠 Technologies Used
- **HTML5**: Semantic structuring
- **CSS3**: Custom properties (variables), CSS Grid, Flexbox, media queries, animations
- **Vanilla JavaScript**: ES6+ modules for interactivity (No jQuery or React)

*(Note: While the projects showcased within the portfolio use technologies like React, TypeScript, Python, and Node.js, the portfolio itself is built strictly with HTML/CSS/JS).*

## 🚀 How to Run Locally
1. Clone or download this repository.
2. Navigate to the project folder.
3. Open `index.html` in any modern web browser.
   - Alternatively, use a local server like VS Code Live Server for hot-reloading:
     `npx serve .` or click "Go Live" in VS Code.

## 📝 Customizing Content
To update the portfolio for future experiences or projects:
1. Open `index.html`.
2. Locate the respective section (`#projects`, `#experience`, etc.).
3. Follow the existing semantic structure (`<article class="project-card">`, etc.) to add or replace content.
4. Replace placeholder links (`href="#"`) with live repository or demo URLs when available.
